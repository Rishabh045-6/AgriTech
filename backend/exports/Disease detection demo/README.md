# 🌱 Crop Disease Detection Demo

This Streamlit app demonstrates crop disease detection using
Sentinel-2 satellite time-series and Transformer-based deep learning models.

## 🚀 Features
- Polygon-based field selection
- Automatic Sentinel-2 data fetching
- NDVI & vegetation index visualization
- Transformer-based disease prediction
- Binary output: Healthy / Diseased

## 🧠 Model
- Input: NDVI-based time-series window
- Architecture: Transformer Encoder
- Output: Single disease probability
- Loss: BCEWithLogitsLoss
